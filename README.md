## Русский

Репозиторий содержит лабораторные работы, выполненные в рамках дисциплины Веб-программирование.

### Содержание репозитория

**Лабораторные работы:**

- [Лабораторная работа №1](Lab1/) - материалы и исходный код первой лабораторной работы.
- [Лабораторная работа №2](Lab2/) - материалы и исходный код второй лабораторной работы.

### Используемые технологии

В зависимости от задания используются основные веб-технологии:

- **HTML** - создание структуры веб-страниц.
- **CSS** - оформление и адаптивная вёрстка.
- **JavaScript** - реализация интерактивности и логики приложений.

Каждая лабораторная работа размещена в отдельной директории и содержит соответствующие файлы проекта.

## English

This repository contains laboratory assignments completed as part of the Web Programming course.

### Repository Contents

**Laboratory assignments:**

- [Laboratory Work №1](Lab1/) - source code and materials for the first laboratory assignment.
- [Laboratory Work №2](Lab2/) - source code and materials for the second laboratory assignment.

### Technologies

Depending on the assignment, the projects use the following core web technologies:

- **HTML** - structuring web pages.
- **CSS** - styling and responsive layouts.
- **JavaScript** - implementing interactivity and application logic.

Each laboratory assignment is stored in a separate directory containing its respective project files.
